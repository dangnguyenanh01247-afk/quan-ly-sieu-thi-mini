# QUẢN LÝ SIÊU THỊ MINI

## 1. Giới thiệu
Đây là chương trình quản lý siêu thị mini được xây dựng bằng ngôn ngữ lập trình C, phục vụ môn học Kỹ thuật Lập trình C.

## 2. Chức năng chính
- Quản lý thông tin hàng hóa.
- Thực hiện các chức năng bán hàng.
- Lưu trữ và xử lý dữ liệu theo yêu cầu của chương trình.

*Lưu ý: Điều chỉnh danh sách này theo các chức năng thực tế mà nhóm đã lập trình.*

## 3. Công nghệ sử dụng
- Ngôn ngữ: C
- Công cụ quản lý mã nguồn: GitHub
- Trình biên dịch: GCC

## 4. Cách biên dịch và chạy
Nếu file chương trình chính là `pos_sieuthi.c`, mở Terminal tại thư mục chứa file và chạy:

```bash
gcc -Wall pos_sieuthi.c -o pos_sieuthi
```

Sau đó chạy chương trình:

- Windows:
```bash
pos_sieuthi.exe
```

- Linux/macOS:
```bash
./pos_sieuthi
```
